# 연애 질문 세부 유형 분류표 v0.1 (2026-10-18 · 검수 전)

타로에만 있는 질문 유형(상대 마음·시기·할까요·운세)을 일상어와 잇기 위해, 국내외 매거진·연애 코치·타로 질문 자료를 조사해 **세부 유형 38개**로 나눴습니다. 분류 AI(프롬프트 A)는 연애 고민에 `qsub` 코드를 붙이고, 결과 AI는 그 상황 이름과 되묻기 방향(`reframe`)을 받아 질문에 답하지 않고 "지금 내 마음과 할 수 있는 것"으로 옮겨 말합니다.

## 2. 조사에서 보인 것

1. **상대 마음 묻기가 가장 많습니다.** 기사 140건 중 84건이 상대 마음, 67건이 할까요·될까요, 31건이 시기, 14건이 운세를 다룹니다. 한국·영어권 모두 순서가 같습니다.
2. **매거진은 '신호 해석 → 내가 할 수 있는 것'으로 끝맺습니다.** 답장 속도·먼저 약속을 잡는지·미래 얘기를 피하는지 같은 신호를 짚되, 결론은 상대 판정이 아니라 내 기준·내 행동입니다. 쏠 타로의 되묻기 방향(질문에 답하지 않고 내 마음으로 옮기기)과 같은 구조라 그대로 쓸 수 있습니다.
3. **한국은 '단계' 은어, 영어권은 '행동' 이름이 많습니다.** 한국: 썸·선톡·읽씹·안읽씹·애프터·삼프터·어장·환승·자니?. 영어권: ghosting·breadcrumbing·situationship·orbiting·love bombing·soft launch. 같은 상황끼리 묶어 은어 67개를 세부 유형에 연결했습니다(엑셀 '연애 은어').
4. **타로 질문 자료에서는 재회·상대 속마음·시기가 가장 많고**, 타로 리더들이 "그 사람이 나를 좋아하나요" 대신 "이 관계에서 내가 할 수 있는 것은?"으로 질문을 바꾸라고 권합니다(Angelorum·The Tarot Lady). 쏠 타로 공통 규칙 13과 같은 방향입니다.
5. **남성 시점 질문**은 "왜 화났나", "애프터 받아 줄까", "관심 있는 건가"가 많아 OM-ANGRY·OM-FIRSTDATE로 따로 뒀습니다.
6. **위험 신호와 겹치는 질문**: 잠수·재회 상황의 "연락해도 될까"는 상대가 차단·거절했으면 연락을 권하지 않아야 하고(반복 연락은 스토킹이 될 수 있음), 러브바밍·바람 의심은 통제·폭력 신호와 섞일 수 있어 폭력 판단을 먼저 합니다. 각 유형의 '주의' 칸에 적었습니다.

## 4. 일상 표현과 되묻기 방향
