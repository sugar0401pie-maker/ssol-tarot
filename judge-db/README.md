## 2. 판별 기준에서 바뀐 것 (프롬프트 A · v2.10)
1. **질문 형식 `qtype`** 추가 — 질문이어도 need는 "그 질문 뒤에서 이 사람이 자기 자신을 위해 바라는 것". 결과 AI(C·D)는 질문에 답하지 않고 "지금 내 마음과 할 수 있는 것"으로 옮겨 말함(공통 규칙 13).
2. **헷갈리는 짝 가르기** 5쌍(쉼↔놓아주기, 연결↔놓아주기, 선택↔시작, 경계↔쉼, 연결↔경계).
3. **쏘웰라 분류기 규칙 옮김** — 글쓴이 자신의 마음으로, 부정·가정은 고르지 않기, 단어가 같다고 고르지 않기.
4. **안전** — 간접 위기 표현, 절망 확신·며칠째 못 먹음 등 주의 신호, 관용 표현은 위기 아님, **단어 없이 행동으로 보는 폭력·통제**(벽을 침, 카톡 보여 달라, 집 앞에 옴, 월급을 가져감).
5. 기존 예시 1개 정답 조정: "이 관계를 끝내고 싶은데 용기가 안 나요" 선택 → **시작**(끝내기로 마음은 있고 말할 용기가 막힘).
