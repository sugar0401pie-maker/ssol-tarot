# v4.3 결제 분석용 기록 (eventFields)

결제 여부와 함께 한 줄씩 남겨 주세요. 고민 원문은 넣지 않아요(원문은 기존 worry 테이블에만).

| 칸 | 뜻 | 왜 |
|---|---|---|
| id | 사용자·세션 id | A/B 배정과 같은 id |
| len, long | 고민 글자 수, 41자 이상 여부 | 41자 이상이면 결제율 2.5배(8.8% vs 3.6%) |
| area, domain | A2 세부 영역, A 분류 영역 | 취업·시험을 진로와 나눠 보기 |
| table, side, strength | 점수표, 결론 쪽, 강도 | 표별 전환율(새 인연 2.4%, 다가가기 9.8%) |
| want, love_status, stage, control | 듣고 싶은 답, 연애 단계, 단계, 답이 누구 손에 | 상대 마음 13%, 솔로 1.9% 등 구간 추적 |
| forecast | 예측형 선택지를 썼는지 | 예측 질문 재설계 효과 |
| teaser, answer_kind | 3·4쪽 예고 문구, 7쪽 답 먼저 종류 | 예고 문구별 결제율 |
| mid_key | 중간 결과 문장 묶음 | 연애 단계별 문장 효과 |
| placeholder_variant | 입력창 A/B | 41자 이상 비율 → 결제율 |
| paid | 결제 여부 | 목표 지표 |

**시험 운영:** 한 번에 한 가지만 바꿔요. 전환율 5%→7% 차이를 가르려면 한쪽에 약 2,200명이 필요해요(하루 150~280명 기준 2~3주). 순서: ① 입력창 A/B → ② 3쪽 예고 → ③ 새 인연 예측형 선택지.
