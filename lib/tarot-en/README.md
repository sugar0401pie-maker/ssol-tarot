# lib/tarot-en — 영문판 패키지 코드(2026-11-06)

한국어 패키지 원본(`lib/tarot/*.js`)을 복사해 **한국어에 묶인 곳만** 영어로 바꾼 것(기획 `docs/spec/en/00_읽어주세요_영문판_v1.2.3.md`의 '코드에서 바꿀 곳').
계산(점수표·방향·셔플)은 한국어 원본을 그대로 불러 쓰고, 이 폴더에는 화면에 나가는 글·검증 규칙이 다른 파일만 둔다.

- 화면 코드가 읽는 표시(`[카드 이미지 3장]`, `[[읽기 지도: …]]`, 그 안의 `(역방향)`)는 기계용이라 한국어 그대로 둔다(`lib/client/pageBlocks.ts`가 같은 표시로 읽음).
- 영어 문장 틀은 **개발(Claude) 초안** — 원어민 검수 대상(데이터에 없는 문장만 여기 있다. 데이터에 있는 문장은 데이터가 쓰인다).
- 한국어 원본을 고치면(패키지 새 판) 같은 곳을 여기도 맞춘다.
