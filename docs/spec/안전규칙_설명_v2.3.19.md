# 쏠 타로 하우스 안전 규칙 설명 (v2.3.19 · 2026-11-15)

고민 글에서 위험 신호를 어떻게 가려내고, 가려낸 뒤 무엇을 하는지 정리한 문서예요. 낱말 전체 목록과 바꾼 내역은 같은 이름의 엑셀(`쏠타로_안전규칙_v2.3.19.xlsx`, 같은 내용의 JSON)에 있어요.

- 기준: 개발 패키지 v2.3.19의 코드 `03_코드/safety.js`, 데이터 `02_데이터/tarot_data.json`의 `safety_keywords`, AI 분류 기준 `01_설계/ai-prompts-tarot-v2.md`.
- 단계 구분과 키워드 정리는 CSO 결정이에요(10월 22일, 11월 14일, 11월 15일). 상담사 확정 전이에요.
- 운영 사이트에는 아직 반영되지 않았어요. 개발이 v2.3.19를 올려야 적용돼요.

## 1. 하드 룰 (11월 15일)

**죽음·자살·자해를 직접 가리키는 낱말이 없으면 위기가 아니라 주의로 판정해요.** 문맥으로 미루어 짐작되는 표현은 모두 주의예요.

| | 위기 (카드가 멈춤) | 주의 (결과는 나가고 109 안내 한 줄) |
|---|---|---|
| 기준 | 직접 낱말이 있음 | 직접 낱말이 없고 문맥으로 짐작됨 |
| 예 | 죽고 싶어요, 죽을까 생각해요, 자해, 죽는 방법을 검색했어요, 유서 | 저를 다치게 한 적이 있어요, 저를 해치는 습관, 아빠 돌아가시고 나도 따라가고 싶다, 가족들한테 편지를 써 뒀어요, 약을 모아 뒀어요, 더 버틸 이유가 안 보여요 |

이 규칙은 키워드와 AI 분류 기준에 똑같이 넣었어요. 그래서 "저를 다치게 한 적이 몇 번 있어요"처럼 자해 행동을 '자해'라는 낱말 없이 쓴 글은 이제 카드와 결제가 그대로 진행되고, 마지막 쪽(10쪽) 맨 아래에 109 안내 한 줄이 붙어요.

## 2. 판정 단계

고민 글 하나에 '위기 단계'(위기·주의·보통)와 '관계 속 위험'(폭력·두려움·없음)을 따로 붙여요.

| 단계 | 무엇이 해당하나 | 서비스가 하는 일 |
|---|---|---|
| 위기 | 죽음·자살·자해를 직접 가리키는 낱말이 있는 글 | 카드와 결제로 넘어가지 않고 안전 안내 화면에서 멈춤 |
| 주의 | 문맥으로 짐작되는 글, 소극적 표현(사라지고 싶다, 안 깼으면, 살 이유를 모르겠다), 죽으면·죽을까 봐, 한 달 이상 못 먹음·못 잠, 술 의존, 방에서 안 나감, 굶기 | 결과와 방향은 그대로, 마지막 쪽 맨 아래에 109 안내 한 줄 |
| 폭력 | 구체적 행동만: 때림·밀침·목 조름·가둠, 협박, 휴대폰·비밀번호 검사, 위치 강요, 돈을 뺏음, 스토킹 | 방향 계산을 끔, 1366·112 안내 상자, 상대에게 다가가는 실천을 뺌 |
| 두려움 | 그 사람이 무섭다, 화낼까 봐 말을 못 함, 물건 던지기·벽이나 책상 치기 | 방향 계산은 하고 1366 안내 상자만 |
| 보통 | 그 밖 | 그대로 진행 |

## 3. 판정 방식

1. 고민을 제출하면 서버가 키워드로 바로 확인해요. 위기면 카드 섞기로 가지 않아요.
2. 카드를 섞는 동안 AI가 글 전체를 읽고 다시 판정해요.
3. 두 결과 중 높은 쪽을 따라요. 낮추는 쪽으로는 합치지 않아요.
4. 카드를 섞거나 뽑는 중에 AI가 위기로 판정하면 그때 안전 화면으로 가요.

## 4. 위기 키워드 (23개 + 규칙 1개)

죽고싶 · 죽어버리 · 죽을지 · 죽을래 · 죽어야 · 죽을생각 · 언제죽 · 죽는게나을 · 죽는방법 · 죽을방법 · 자살 · 자해 · 극단적선택 · 유서 · 목숨을끊 · 뛰어내리 · 삶을끝내 · 인생을끝내 · 세상을떠나고싶 · 인생그만하고싶 · 그만살려 · 그만살래 · 그만살까

규칙: '죽을까'가 있고 바로 뒤가 '봐'가 아닐 때.

'죽을·죽어·죽는·죽겠'은 낱말 그대로 넣지 않았어요. "죽을 것 같아요", "죽어라 공부", "설레 죽는", "배고파 죽겠어" 같은 관용 표현에서 카드가 멈추기 때문이에요.

## 9. 정해지지 않은 것

1. **직접 낱말은 아닌데 위기에 남아 있는 표현.** 그만 살려·살래·살까, 인생 그만하고 싶, 삶을·인생을 끝내, 세상을 떠나고 싶, 뛰어내리. 하드 룰을 그대로 적용하면 주의로 가야 하는데, 정해 주신 적이 없어 위기에 두었어요.
2. **주의 단계의 안내 위치.** 지금은 마지막 쪽(10쪽) 맨 아래 작은 글씨 한 줄이에요. 결제 전에도 들어가지만 10쪽까지 넘겨야 보이는 자리예요. 주의로 옮긴 글이 늘어서 이 자리가 더 중요해졌어요.
3. 위기 화면의 문구와 그림의 상담사 승인.
4. 서비스에서 '보통'으로 결과가 나간 고민 9건의 상담사 판정.
5. 보통 글을 위기로 잘못 멈추는 비율, 폭력 글에 방향이 나간 건수는 운영과 같은 조건으로 재 본 적이 없어요.
