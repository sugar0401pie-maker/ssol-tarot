# 작심삼일 챌린지 · 풍등 날리기 — 타로 적용 설계 (개발 패키지 v3.8)

> **v3.7 결정 (CSO 11/23):** "새로 쓸 문장 있어도 괜찮아. 2안으로 할게. 대신 이틀째에 해보면 좋겠음. 3일째에 정리하는게 좋아보임. 중간에 뭔가 행동이 들어가지 않으면 3일까지 이어지지 않거든"
> → **2안(갈래를 따라가는 챌린지) 확정, 사흘 순서는 1일차 적기 → 2일차 해 보기 → 3일차 정리하기.** 2일차 해 보기는 3번 카드 × 밖 활동 표(초안)로 고르고, 1주일·1달은 해 보기를 이어 가요. 아래 2절 표의 순서(적기 → 정리하기 → 해 보기)는 옛 안이에요. 챌린지 문장 데이터는 다음 판에 드려요.

> **개발 안내:** 이 문서는 기획 제안 v1.4와 같은 내용이에요. **풍등(4·5절)은 기획에서 더 구체화 중이라 개발 보류**예요. 챌린지도 1안·2안이 아직 정해지지 않아 지금은 화면·데이터 칸 설계 참고용이고, 정해지면 데이터를 드려요. 확정된 것: 인증 사진은 서버에 원본째 보관(사진 속 정보 지우지 않음, 화면용 사본 따로), 쏘웰라 친근한 말투 예시.

작성일 2026-11-23 · 쏠 타로 하우스 · 기준: 개발 패키지 v3.5.2

> **v1.4 (2026-11-23):** 풍등을 A안(챌린지 전에 다짐·2027 바람을 적고 3일 채우면 날리기)으로 정리하고, 990원 이용권 문구를 그에 맞춰 고침(CSO).
> **v1.3 (2026-11-23):** 사진 속 정보(위치 등)를 지우지 않고 원본째 보관하기로 바꿈(CSO). 「타로 카드와 밖 활동 잇기」 표를 더함. 쏘웰라 말투 예시는 CSO가 좋다고 확인.
> **v1.2 (2026-11-23):** 「인스타 스토리로 바로 보내기」를 더했어요.
> **v1.1 (2026-11-23):** 인증 사진은 서버에 받기로 정함(CSO). 인증 형태 세 가지 안을 빼고, 사진을 받을 때 함께 해야 할 일로 바꿨어요. 나머지는 v1과 같아요.

CSO 방향(11/23): 테스트 마지막 화면에서 작심삼일 챌린지를 권하고 실제로 할 수 있게 만든다(1·2·3일차 + 1주일 + 1달). 행동 위주, 인스타 스토리에 올릴 수 있게("갓생 산다"). 집에서 다이어리를 쓰고 찍어 올려도 된다. 쏘웰라에서 3일 도장(리워드), 공유하면 리워드. 쏘웰라 말투는 더 친근하게. 풍등 날리기(쏘웰라)와 990원 결제자 풍등 1회 이용권.

> 사주 쪽(v1.6.0, 11/23)에 같은 결정으로 13쪽 작심삼일 · 14쪽 쏘웰라 구성을 이미 잡아 두었어요. 서비스끼리 같은 모양이면 쏘웰라에서 받기 쉬우니, 타로도 같은 칸 구성을 따르는 쪽으로 제안해요.

## 1. 지금 타로 해결책은 이렇게 되어 있나요?

**아니요. 기간 틀도, 인증·공유 칸도 없어요.**

| 항목 | 지금 (v3.5.2) | 챌린지에 필요한 것 |
|---|---|---|
| 기간 | 9쪽 **오늘 / 3일 안에 / 이번 주** 3칸 | **1일차 / 2일차 / 3일차 / 1주일 / 1달** 5칸 |
| 3일 | '3일 안에' 한 가지 (사흘에 걸쳐 하나) | 날마다 하나씩, 이어지는 세 가지 |
| 1달 | 없음 | 새로 필요 |
| 어디서 고르나 | 오늘 = 3번 카드(44가지), 3일 안에 = 묶음(26주제)의 실천 은행, 이번 주 = AI 한 줄 | 같은 틀 + 갈래(까닭)를 따라가게 |
| 실천 형태 (실천 은행 260개) | 글 51% · 행동 22% · 말 18% · 생각 5% · 몸 4% | **찍어서 남길 수 있는 것** 위주 |
| 다른 사람이 있어야 하는 실천 | 8% (20개) | 집에서 혼자 할 수 있는 길이 늘 있어야 함 |
| 인증·공유 | 없음 | 무엇을 찍을지, 스토리 한 줄 |

좋은 점도 있어요. 실천 은행의 절반이 '글'(적기)이라 **다이어리를 써서 찍어 올리는 방식과 잘 맞아요.** 문제는 '말'(18%)과 '생각'(5%)이에요. 말은 상대가 있어서 찍기 어렵고, 생각은 남는 게 없어요.

## 2. 대안 2가지

### 1안 — 지금 있는 실천을 5칸으로 다시 늘어놓기 (빠름)

| 칸 | 어디서 가져오나 |
|---|---|
| 1일차 | 3번 카드의 '오늘' 실천 (지금 9쪽 오늘, 카드 44가지) |
| 2일차 | 묶음 실천 은행의 '3일 안에' 실천 |
| 3일차 | 3번 카드의 '3일' 실천(three) — 지금 데이터에 있지만 화면에 안 쓰는 칸 |
| 1주일 | 3번 카드의 '이번 주' 실천(week) |
| 1달 | **새로 써야 함** — 카드 44가지 또는 묶음 26주제 |

- 실천마다 칸 3개를 더해요: `proof`(무엇을 찍나), `story`(스토리 한 줄, 20자 안), `home`(집에서 하는 법, 밖에서 하는 실천일 때).
- 좋은 점: 대부분 이미 있는 문장이라 빨라요. 새로 쓸 것은 1달 칸과 칸 3개뿐이에요.
- 걱정되는 점: 사흘이 서로 다른 출처라 **"이어지는 사흘"로 읽히지 않을 수 있어요.** 그리고 카드·묶음 기준이라 그 사람의 까닭(갈래)과 상관없이 나가요.

### 2안 — 갈래를 따라가는 챌린지 (사주와 같은 모양, 권고)

- 첫 갈래의 **종류**(마음 · 상태 · 여건 · 선호)로 사흘의 꼴을 정하고, 묶음으로 내용을 채워요.
- 사흘은 **적기 → 정리하기 → 해 보기** 순서로 이어지고, 날마다 꼴이 달라요(사주와 같은 규칙: 두 가지 이상 섞기).
- 날마다 칸: `text`(집에서 하는 법 — 기본), `out`(밖에서 해도 되는 법 — 선택), `proof`(찍을 것), `story`(스토리 한 줄).

| 첫 갈래 종류 | 1일차 (적기) | 2일차 (정리하기) | 3일차 (해 보기) |
|---|---|---|---|
| 마음 | 걸리는 마음을 한 줄로 적기 | 그 마음이 맞는지 근거 두 개씩 적기 | 마음과 다르게 작은 행동 하나 |
| 상태 (지침) | 오늘 기운 점수 적기 | 기운을 빼는 것 하나 지우기 | 10분 쉬는 시간 넣기 |
| 여건 | 걸리는 조건을 숫자로 적기 | 바꿀 수 있는 것 / 없는 것 나누기 | 바꿀 수 있는 것 하나 해 보기 |
| 선호 | 바라는 장면 한 줄 | 바라는 것 중 하나 고르기 | 그쪽으로 한 걸음 |

- 1주일 = 3일차를 사흘 더 되풀이하고 돌아보기, 1달 = 한 주에 한 번 같은 것 하기(4번).
- 좋은 점: 까닭에 맞는 챌린지가 나가요(과제 3의 해결과 같은 길). 사주와 같은 칸이라 쏘웰라가 두 서비스를 같은 방식으로 받아요.
- 걱정되는 점: 문장을 새로 써야 해요(갈래 종류 4 × 묶음 25 × 5칸 기준 약 500칸). 2안을 넣기 전까지는 1안으로 먼저 열 수 있어요.

### 예시 (2안)

**예시 1 · 그만둘지 고민 (WK-QUIT), 첫 갈래 "너무 지쳐서 지금 그만두고 싶은데…"(상태)**

| 칸 | 집에서 (기본) | 밖에서 (선택) | 찍을 것 | 스토리 한 줄 |
|---|---|---|---|---|
| 1일차 | 자기 전 오늘 기운을 0~10으로 적고, 가장 지치게 한 일 하나 적기 | — | 다이어리 한 칸 (내용은 가려도 돼요) | 작심삼일 1일차, 나를 체크함 |
| 2일차 | 내일 일정에서 안 해도 되는 것 하나 지우기 | — | 지운 줄이 보이는 할 일 목록 | 빼기도 실력 |
| 3일차 | 점심이나 퇴근 뒤 10분, 폰 없이 쉬는 시간 넣기 | 회사 근처 한 바퀴 걷기 | 타이머 화면 또는 걷는 길 | 3일 완주, 10분 나를 위해 |
| 1주일 | 10분 쉬기를 사흘 더 하고, 주말에 기운 점수 비교 | | 한 주 기운 점수 표 | 일주일 갓생 인증 |
| 1달 | 한 주에 한 번 기운 점수를 적고, 그만둘지 다시 생각해 보기 | | 한 달 점수 표 | 한 달 동안 나를 봤다 |

**예시 2 · 인연이 언제 올지 (LV-WHEN), 첫 갈래 "새로운 사람을 만날 기회도 없는데…"(마음)**

| 칸 | 집에서 (기본) | 밖에서 (선택) | 찍을 것 | 스토리 한 줄 |
|---|---|---|---|---|
| 1일차 | 지난 한 달 새로 알게 된 사람이 몇 명인지 적기 | — | 다이어리 한 칸 | 작심삼일 1일차 |
| 2일차 | 내가 편하게 갈 수 있는 자리 세 곳 적기(동호회·수업·온라인 모임) | — | 적은 목록 | 내 동선 점검 완료 |
| 3일차 | 그중 한 곳 일정을 찾아 달력에 넣기 | 그 자리에 한 번 가 보기 | 달력 화면 또는 그곳 사진 | 3일 완주, 한 걸음 |
| 1주일 | 넣어 둔 일정에 한 번 가 보거나, 온라인 모임에 글 하나 남기기 | | 갔던 곳 또는 남긴 글(이름 가림) | 일주일 갓생 인증 |
| 1달 | 한 주에 한 번 새 자리 하나 | | 네 번의 기록 | 한 달 동안 새 문 네 개 |

밖으로 나가지 않는 사람도 1일차부터 1달까지 **집에서만 끝까지 할 수 있게** 짰어요.

## 3. 화면 구성 (타로 결과지 마지막 쪽 + 쏘웰라)

사주와 같은 순서로 제안해요.

| 자리 | 내용 |
|---|---|
| 결과지 9쪽 | 이번 주 실천 → **작심삼일 챌린지** 카드로 바꿈(1·2·3일차 + 1주일 + 1달, 날마다 '찍을 것'과 '스토리 한 줄') |
| 결과지 10쪽 (마지막) | ① 챌린지 권유 → ② 쏘웰라에서 3일 도장 받기 → ③ 스토리에 올리면 리워드 → ④ 쏘웰라에 물어볼 말 → ⑤ **맨 끝: 풍등 1회 이용권**(아래 5절) |
| 쏘웰라 | 날마다 도장 + 인증 올리기, 3일 다 채우면 큰 도장, 스토리 카드 만들어 주기 |

**인증 형태 — 사진을 서버에 받음 (CSO 결정 11/23)**

CSO: "사진을 서버에 받아야짘ㅋㅋ" → 인증 사진은 서버에 저장해요. 웹페이지에서도 [사진 올리기]를 누르면 휴대폰 카메라나 사진첩이 열려요(아이폰 사파리·안드로이드 크롬 모두 가능). 사진이 없을 때를 위해 글 카드(한 줄 쓰면 스토리 카드로 만들어 줌)도 같이 둬요.

사진을 받으면서 함께 해야 할 일:

| 할 일 | 까닭 | 누가 |
|---|---|---|
| **원본 그대로 보관** | CSO: "위치정보 지우지마 어떤 정보도 지우지마 이 정보들을 우리가 나중에 써먹을거야~!" — 사진 속 정보(찍은 장소·시각·기기 등)를 지우지 않고 원본 파일째 보관 | 개발 |
| 화면용 작은 사본 따로 만들기 | 원본은 그대로 두고, 화면에 보여 줄 때만 작게 만든 사본을 씀(크기를 줄이면 사진 속 정보가 빠지는 경우가 많아 원본과 따로 둠) | 개발 |
| 사진 속 정보 따로 뽑아 저장 | 나중에 쓰기 쉽게 찍은 장소·시각을 칸으로 뽑아 둠 | 개발 |
| **위치 정보 수집·이용 동의 받기** | 사진 속 위치는 개인 위치정보라, 모으고 쓰려면 이용 목적을 알리고 따로 동의를 받아야 할 가능성이 커요. 위치 정보를 서비스에 쓰면 위치정보 관련 신고가 필요한지도 확인해야 해요 | 법률 검토 |
| 저장소 정하기 | 점성술 DB 설계가 Supabase라 같은 곳의 파일 저장소 후보 — 확인 필요 | 개발 |
| 남에게 안 보이게 (본인만 보기) | 인증 사진은 기본으로 본인만 봐요. 공유는 본인이 스토리로 직접 | 개발 |
| 부적절한 사진 걸러 내기 | 누구나 올릴 수 있어요 — 자동 검사 또는 신고 | 개발·운영 |
| 다른 사람 얼굴·이름·대화 안내 | 올리기 전 "다른 사람이 보이지 않게 찍어 주세요" + 가리기 | 기획·개발 |
| 보관 기간·삭제 | 나중에 쓰려면 보관 기간을 길게 정하고 그 기간을 알려야 해요. 본인이 지우고 싶을 때 지울 수 있게는 해 둬야 해요 | 기획 결정 |
| 개인정보 처리방침에 사진·위치 수집 넣기 | 무엇을(사진, 찍은 장소·시각), 왜(나중에 쓸 목적), 얼마나 보관하는지 적어야 해요 | 법률 검토 |

스토리 카드에는 고민 내용·카드 이름 없이 "작심삼일 ○일차 + 스토리 한 줄 + 쏠 로고"만 넣어요(고민이 드러나지 않게).

**인스타 스토리로 바로 보내기 (CSO: "이건 되면 너무 좋겠당..")**

웹페이지에서도 휴대폰의 공유 창을 띄워, 만든 스토리 카드(이미지)를 인스타그램으로 넘길 수 있어요. 웹 표준 공유 기능(Web Share API)으로 이미지 파일을 넘기는 방식이에요.

| 단계 | 화면 |
|---|---|
| 1 | 인증을 올리면 쏘웰라가 스토리 카드(1080×1920)를 만들어 보여 줌 |
| 2 | [인스타 스토리에 올리기] → 휴대폰 공유 창이 열림 → 인스타그램 선택 → 스토리로 올리기 |
| 3 | 공유 창이 안 열리는 기기·브라우저면 버튼이 [이미지 저장하기]로 바뀌고 "저장한 이미지를 인스타 스토리에 올려 주세요" 안내 |

- 개발 메모: 버튼을 보여 주기 전에 이 기기가 파일 공유를 지원하는지 먼저 확인하고(`navigator.canShare({ files })`), 안 되면 저장하기로 바꿔요. 공유는 버튼을 누른 순간에만 열 수 있어요.
- 확인 필요: 공유 창에 인스타그램이 뜨고 '스토리'를 고를 수 있는지는 기종·인스타 앱 판에 따라 달라요. 아이폰·안드로이드 실제 기기로 먼저 시험해 봐야 해요. 카카오톡 같은 앱 안 브라우저에서는 안 될 수 있어요.

## 4. 풍등 날리기 (쏘웰라) — 챌린지 전에 적고, 3일 채우면 날리기

CSO(11/23, A안에 단 의견): "작심삼일 챌린지 하기 전에 내 다짐하고 2027년에 잘됐으면 좋겠는 내용을 적어달라고 하면 될 듯"

→ **A안(완주 뒤에 날리기)으로 정리했어요.** 풍등에 적는 것은 두 가지예요.

| 순서 | 화면 | 적는 것 / 하는 것 |
|---|---|---|
| 1 | 풍등 준비 (챌린지 시작 전) | **나의 다짐** 한 줄 — 예: "사흘 동안 나를 먼저 챙기기" |
| | | **2027년에 잘됐으면 하는 것** 한 줄 — 예: "원하는 곳으로 이직하기" |
| 2 | 작심삼일 1·2·3일차 | 날마다 인증하면 풍등에 불이 하나씩 켜짐(1일차 1개 → 3일차 3개) |
| 3 | 3일 채운 날 | **[풍등 날리기]** — 적어 둔 다짐과 2027 바람이 담긴 풍등이 하늘로 |
| 4 | 날린 뒤 | 스토리 카드(풍등 그림 + 다짐 한 줄, 2027 바람은 넣을지 본인이 고름) + 1주일·1달 챌린지 이어 가기 |

화면 문구 초안:

> **챌린지를 시작하기 전에, 풍등에 마음을 적어 볼까요?**
> 나의 다짐 ____________________
> 2027년에 잘됐으면 하는 것 ____________________
> 3일을 채우면 이 풍등을 날릴 수 있어요 🏮

제가 정한 것(확인 부탁):
- **3일은 꼭 연달아가 아니어도** 세 번 인증하면 날릴 수 있게 했어요. 이용자 모두 불안·걱정을 안고 오는 사람들이라, 하루 빠졌다고 처음부터 다시 하게 하면 포기하기 쉬워서예요.
- 날린 풍등의 다짐·바람은 지우지 않고 보관해요(1주일·1달 챌린지, 2027년에 다시 보여 주기 등에 쓸 수 있음).

## 6. 확인이 필요한 것 (결정은 CSO)

1. **미성년 이용자.** 운영 글에 고등학생으로 보이는 글이 있어요. 스토리 공유와 리워드를 미성년에게도 같게 줄지 정해 주셔야 해요.
2. **안전 '주의' 단계 이용자.** 지금 주의 단계에는 더 세게 문장·기저 생각을 안 붙여요. 챌린지와 공유 권유도 같은 기준(권유는 하되 공유·리워드 강조는 빼기 등)으로 둘지 정해 주세요.
3. **공유하면 리워드를 주는 것.** 대가를 받고 올리는 게시물은 광고 표시가 필요할 수 있고, 인스타그램에도 홍보 이벤트 규칙이 있어요. 리워드 종류를 정할 때 법률 검토를 함께 받으시길 권해요(저는 법률 전문가가 아니에요).
4. **인증 사진 속 다른 사람.** 사진에 다른 사람 얼굴·이름·대화가 들어갈 수 있어요. 올리기 전 안내와 가리기 기능이 필요해요.
5. **쏘웰라 3일 무료와의 관계.** 점성술 쪽 기록에 "쏘웰라는 처음 3일 무료"가 있어요. 3일 챌린지 기간과 맞추면 자연스러워요.

## 정해 주실 것

1. 1안(지금 실천 다시 늘어놓기)으로 먼저 열지, 바로 2안(갈래 따라가기)으로 갈지.
2. 인증 사진 보관 기간(예: 챌린지 끝나고 며칠 뒤 삭제), 공유 리워드를 무엇으로 확인할지(공유 창 완료 / 스토리 태그).
3. 결제하지 않은 사람도 풍등을 날릴 수 있게 할지, 3일을 꼭 연달아 해야 하는지.
4. 위 6절의 1~3.
