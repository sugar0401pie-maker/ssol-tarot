# 여러 고민을 한꺼번에 썼을 때 (v2.3.21 · 2026-11-15)

CSO 결정: 여러 고민을 한꺼번에 쓰면 **카드를 뽑기 전에 하나를 고르게 하고**, 결과 3쪽 첫 줄에서 **어떤 고민으로 카드를 읽었는지 먼저 알려 줘요.** 목적은 '여러 고민이 한꺼번에'(UF-ALL)로 가는 글을 줄이는 것이에요.

- 데이터 `02_데이터/multi_worry.json`, 코드 `03_코드/multiWorry.js`, 프롬프트 `08_판별DB/A2_고민틀_프롬프트_v4.13.txt`.
- AI를 부르지 않아요. 문구는 CSO 문구와 Claude 초안이고 CSO 검수 전이에요.

## 1. 화면

고민 제출 → 안전 확인(키워드) → **여기서 한 번 물음** → 카드 섞기.

| 자리 | 문구 |
|---|---|
| 질문 | 어느 고민으로 카드를 뽑을까요? |
| 작은 글씨 | 타로는 한 고민을 볼 때 가장 정확해요. {닉네임}님이 가장 알아보고 싶은 고민을 하나만 골라 주세요. |
| 선택지 | 글에서 찾은 고민(예: 시험·공부 고민 / 연애 고민), 최대 4개 |
| 마지막 선택지 | 모두 이어진 한 가지 고민이에요 |

- 위기 글에는 보여 주지 않아요.
- 이 질문이 나가면 짧은 고민 다시 묻기는 건너뛰어요(질문이 두 번 나가지 않게).

## 2. 언제 묻나

서로 다른 묶음의 낱말이 둘 이상 나오고, 각 낱말 뒤 25자 안에 묻는 말(될까·언제·궁금·고민·싶·~운 등)이 있을 때만 물어요.

| 묶음 | 선택지 이름 |
|---|---|
| 연애 | 연애, 결혼 |
| 일 | 직장, 취업, 시험·공부, 진로 |
| 돈 | 돈 |
| 건강 | 건강 |

- 같은 묶음 안(직장과 취업, 연애와 결혼)은 한 고민으로 보고 묻지 않아요.
- 긴 사연 속에 지나가듯 나온 낱말에는 묻지 않아요("연애 초반인데 … 헤어질지 고민이에요. 직장도 가까운데").
- 인간관계 묶음은 넣지 않았어요. "회사에서 인간관계가 고민"처럼 한 고민인 글에 물어보게 되기 때문이에요.

## 3. 고른 뒤

| 순서 | 함수 | 하는 일 |
|---|---|---|
| 1 | `detectMulti(text, db, {urgent})` | 물어볼지와 선택지를 돌려줌 |
| 2 | `multiQuestion(detect, db, name)` | 질문·작은 글씨·선택지 문구 |
| 3 | `composeFocus(text, choiceId, detect, db)` | 고민 글 끝에 "(고른 고민: 연애)"를 붙임. 이 글을 A2에 보냄 |
| 4 | `applyFocus(frame, detect, choiceId, db)` | A2 결과에 `frame.focus`를 붙임 |
| 5 | `focusLine(frame.focus, db)` | 3쪽 첫 줄 문장. 없으면 null |
| 6 | `eventFields`의 `multi_worry` | 기록용. 예: `asked:work,love|picked:love` |

3쪽 첫 줄 문장:

| 경우 | 문장 |
|---|---|
| 하나를 고름 | 적어 주신 고민 중 ‘연애’ 고민으로 카드를 읽었어요. ‘시험·공부’ 고민은 다음에 따로 뽑아 보세요. |
| 고르지 않고 넘어옴 | 적어 주신 고민 중 ‘시험·공부’ 고민을 중심으로 카드를 읽었어요. |
| 모두 이어진 한 가지 | 줄 없음 |

원문 고민 글은 그대로 보관하고, "(고른 고민: …)"는 A2에 보낼 때만 붙여요. 3쪽 인용에는 원문을 써요.

## 4. A2 프롬프트 v4.13

v4.12의 "두 가지면 먼저 쓴 쪽" 규칙을 바꿨어요.

- "(고른 고민: X)"가 있으면 X의 틀과 세부만 고르고, UF-ALL로 보내지 않아요.
- "이어진 한 가지"면 한 고민으로 읽어요.
- 고른 고민이 없고 두 가지면 더 무거운 쪽(v2.3.24, 프롬프트 v4.16에서 바꿈. 무게를 못 가리면 먼저 쓴 쪽).
- UF-ALL은 고른 고민이 없고 영역 셋 이상을 같은 무게로 물을 때만.

**v4.13은 정답 세트로 재 보지 않았어요.** 운영에 올리기 전에 `run_eval_frame.mjs`로 v4.12와 비교해 주세요.

## 5. 재 본 것

- 실제 고민 2,553건 중 이 질문이 나가는 글: 41건(1.6%).
- 서비스가 UF-ALL로 보낸 25건 중 이 질문이 나가는 글: 16건.
- 나머지 9건은 영역 낱말이 없거나("미래 고민, 내 인생") 묻는 말 없이 낱말만 늘어놓은 글이에요. 이 글들은 v4.13의 UF-ALL 조건(셋 이상을 같은 무게로)으로 줄여야 해요.

## 6. 정해지지 않은 것

1. 선택지 문구와 3쪽 문장의 CSO 검수.
2. 질문을 건너뛸 수 있게 할지. 지금 설계는 고르지 않고 넘어와도 결과가 나가게 되어 있어요.
3. 이 질문 때문에 카드 뽑기 전에 나가는 사람이 느는지. `multi_worry` 기록으로 확인해야 해요.
