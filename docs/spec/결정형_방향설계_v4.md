# 결정형 고민 방향 설계 v4 (2026-10-20 CSO 확정)

## 1. 왜 바꿨나
v3.2까지는 분석과 '마음 둘 곳'만 말하고 결론을 내리지 않았습니다. 그래서 "이직할까 말까" 같은 고민에도 '일과 쉼의 비율' 이야기만 나와 와닿지 않았습니다. v4부터 쏠 타로의 차별점은 **행동을 제안하는 타로**입니다(R12). 사람들이 타로를 보는 이유는 하고 싶은 것이 있는데 막혀 있어서 한 번 밀어 줄 말(nudge)이 필요해서라고 봅니다. 그리고 행동을 하라고 해도, 결국 마음이 움직이지 않으면 하지 않을 사람은 하지 않습니다.

근거(요약):
- Levitt(2021, NBER w22487): 결정을 못 내리던 사람에게 동전을 던지게 했더니, '바꿔라'가 나와 실제로 바꾼 사람이 6개월 뒤 더 행복하다고 답함 → 결론을 '움직이는 쪽'으로 더 자주(R6).
- Masicampo & Baumeister(2011): 목표를 아직 이루지 않았어도 언제·어디서·어떻게 할지 계획을 세우면 같은 생각이 머릿속을 덜 맴돎 → 결론이 어느 쪽이든 이번 주 계획 하나(R11).
- 반대 근거도 확인함: '안 한 후회가 더 오래 간다'(Gilovich & Medvec 1994)는 재현에서 약해짐, 걱정은 행동 대신 쓰이기도 함(Borkovec). 그래서 '무조건 움직여라'가 아니라 '움직이는 쪽을 더 자주 + 어느 쪽이든 구체적 행동'으로 정함.

## 2. 흐름
1. 고민 제출 → A(분류) + **A2(고민 틀)**: worry_type, 선택지, option_axis{move, stay}, 결국 묻는 것, 먼저 풀 물음, 기한, 기간, 원문 구절, **money**, **table**.
2. 안전 확인(S1 urgent, S4 폭력 구체 행동, S4-5 관계 속 두려움). watch 단계는 없앰.
3. 세 장 뽑기 → **lean 계산(코드)** → C(결제 전 문장, 결론을 숨긴 5쪽 첫 문구, 카드별 이유).
4. 결제 → D(5·6쪽) + **E(7쪽 방향·계획, 8쪽 변화, 9쪽 처방, 10쪽 실천)**.
5. buildPages(v3.3) → **buildPagesV4**(11쪽).

AI는 방향을 바꾸지 못합니다. 코드가 정한 결론의 이유만 씁니다.

## 3. 방향 계산 (`03_코드/decision.js`, 데이터 `02_데이터/decision_tables.json`)
- 질문 유형별 점수표 8개: 변화형 3(이직·퇴사 job / 시작·도전 start / 이사·독립 move — CSO가 세 가지로 확정), 관계형 5(다가가기 approach / 재회 reunion / 진전 progress / 지속 continue / 새 인연 newlove).
- 카드 22장 × 정·역 = 44개마다 점수 +2·+1(움직이는 쪽) / −1·−2(머무는 쪽), 0 없음. 표마다 + 카드 26개(v2에서 −1 → +1로 57장 바꿈, 검수표 '바꾼 카드(v2)').
- 합 = 지나온 길×1 + 지금의 흐름×1 + 앞으로의 열쇠×2. **합 ≥ 0 → 움직이는 쪽**(0도 움직이는 쪽), 평균을 빼지 않음.
- 강도: |합| ≥ 3 뚜렷(strong), ≥ 1.5 분명(clear), 그 아래 조금 더(slight).
- 앞으로의 열쇠 카드의 stance가 '조건 바꾸기'면 결론에 "— 단, ○○를 조건으로"(with_condition).
- 결과(모든 뽑기 73,920가지): 표마다 움직이는 쪽 63~67%(v1 39~52%).
- 어느 표를 쓸지: A2의 table → 없으면 연애 세부 유형(qsub) 표 → 없으면 방향 계산 안 함. 내 마음·회복을 묻는 설명형(OM-MYFEEL, OM-EXWHY, TM-HEAL)은 방향 계산 안 함.
- **돈·투자·큰 지출**: 막지 않고 '시작·도전' 표로 계산. 7쪽 방향 아래에 작은 글씨로 "결정적인 판단은 ○○님의 몫이에요. 카드는 금액·조건 같은 세부 내용을 알 수 없어서, 실제 금전 문제에 대한 판단 근거나 기반을 제공하지 않아요. 신중하게 판단해 주세요." — 코드가 붙임(R10). AI는 금액·수익률·종목·시점을 쓰지 않음.

예) 도현님(이직 제안, job 표): 정의 역(−1) + 여사제 정(−1) + 절제 정(−1×2) = −4 → '현재 회사에 남기 — 뚜렷', 열쇠가 조건 바꾸기 카드라 조건이 붙음.

## 4. 화면에 나오는 방식
- 5쪽 첫 문구는 결론을 숨김(R7): 뚜렷·분명 → "{먼저 풀 물음을 줄인 말}, 세 장이 답했어요", 조금 더 → "{기간}의 질문 끝에, 세 장은 한쪽을 골랐어요". 결론은 결제 후 블러 아래 첫 줄과 9쪽 맨 위.
- 7쪽: 결론 → 근거(카드별) → 언제(6개월을 초반·중반·후반으로, 기한이 있으면 기한 기준) → 이렇게 결정해 볼까요?(먼저 풀 물음의 답에 따라) → 가장 중요한 질문 → **이번 주 계획**(언제·어디서·무엇을) → (돈) 작은 글씨.
- 방향·결론 문장에는 '~할 수 있어요/~일 수도' 금지(R4). '결정은 당신에게' 금지.
- 결정형이 아닌 고민도 7쪽 끝에 "이번 주에 이것부터" 계획 하나로 마무리(R12).
