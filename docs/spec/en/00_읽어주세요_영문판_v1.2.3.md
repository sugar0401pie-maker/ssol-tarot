# 쏠 타로 하우스 영문판(Ssol Tarot House) — 개발 참고 자료 v1.2.3

기준일 2026-11-05(처음 만든 날 11-03). 쪽 구성은 한국어 패키지 **v2.3.2**(개발 현행 구성)와 같고, 문장은 한국어 v4.2와 3쪽 **'두 장 중간 결과' 문장 DB v1**을 기준으로 만들었어요. 영문판은 **한국어판과 분리된 별도 테스트**예요. 사이트, 데이터, 프롬프트, 안전 기준을 따로 두고, 코드는 한국어판을 복사한 뒤 아래 '코드에서 바꿀 곳'만 고치면 돼요.

> 모든 영어 문장은 **번역 초안**이에요. 출시 전에 원어민 검수를 받아야 하고, 안전 부분은 임상 전문가 검수가 필요해요.

## 결정이 필요한 것 (CSO)
1. **출시 국가:** 안전 연락처, 결제, 통화가 국가에 따라 정해져요. 지금은 US·UK·CA·AU·GLOBAL 연락처를 모두 넣어 두었어요. 안전 메모에는 접속 국가로 고르고 없으면 GLOBAL을 쓰는 방식을 제안해 두었어요.
2. **가격과 결제:** `{price}`(예: $0.99 / $1.99)와 해외 결제 수단(Stripe 등)을 정해야 해요. 토스페이먼츠는 국내용이에요.
3. **약관·개인정보처리방침 영문판:** 이번 자료에 없어요. 해외 법률(미국 주별 개인정보법, GDPR 등) 검토가 필요해요.
4. **쏘웰라 연결:** 10쪽 안내는 영어로 번역했어요. 다만 쏘웰라 영어 대화가 준비됐는지에 따라 쪽을 유지할지 정해야 해요.

## 검수가 필요한 것
