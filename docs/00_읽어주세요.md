- **결과 11쪽**: 7쪽 카드가 가리키는 방향(결론·근거·언제·이렇게 결정해 볼까요?·가장 중요한 질문·**이번 주 계획**) → 8쪽 **앞으로 이렇게 바뀔 거예요**(새로) → 9쪽 처방(맨 위에 결론 headline) → 10쪽 실천 → 11쪽 쏘웰라

- **1쪽 고민 틀 상자**(선택지·결국 묻는 것·먼저 풀 물음·기한) + "앞으로 약 6개월의 흐름". 사용자가 쓴 말·선택지는 끝까지 그대로(A7 HARD)

- **안전**: 주의(watch) 단계 삭제, 폭력 판정은 구체 행동(신체 폭력·협박·통제·스토킹)만, '그 사람이 무섭다'는 관계 속 두려움(안내만), 차단 언급은 판정 없음

## 핵심 결정

- **카드**: 메이저 아르카나 22장 구조 + 웰니스 재해석(하이브리드). 캐릭터는 쏠 캐릭터 20종 + 바다의 노인 + 단체 카드. **역방향 있음**(셔플 때 카드마다 50%, '그 힘이 아직 안쪽에 머무는 상태'로 해석).
- **시작 흐름(v1.2)**: 인트로(디저트와 동일) → 환영·닉네임 → "타로카드는 처음이신지요?" → (처음이면 안내) → 고민 쓰기 또는 "고민은 마음속으로만" 건너뛰기.
- **방식**: 고민 자유 입력(선택) → 셔플 동안 AI가 영역(6)·감정(8)·필요(6) 백그라운드 분류(확인 화면 없음) → 카드 섞기(다시 섞기 가능, 서버 무작위) → 22장 중 직접 3장 뽑기(뽑는 즉시 뒤집기) → 3장째를 뽑는 순간 백그라운드로 결과 준비.
- **대기 안내**: 모든 대기 화면에 "{닉네임}님의 타로 결과를 분석하고 있어요... (n초 경과)". 오래 걸릴 때의 추가 안내는 미정.
- **결과·결제(v2.7)**: 옆으로 넘기는 8쪽. 무료 = 1~4쪽(세 장 한눈에 + 카드별 세부) + 5쪽 머리(메인 문구·첫 줄·마무리). 유료 1,900원 = 5쪽 나머지(이야기·내 고민에 대어 보면) + 6 처방 · 7 실천 · 8 쏘웰라 안내. 채팅권 없음.
- **리포트**: 8섹션. DB 문장 서버 조립 + 저비용 AI 3곳(고민 분류 / 카드별 연결 한 줄·상황 질문 / 이야기·내 고민에 대어 보면), 모두 코드로 자동 검증 + 실패 시 고정 문장.
- **안전**: 서버 키워드 + AI 판단 중 높은 쪽. urgent면 카드 진행 중단하고 안전 안내, 폭력·통제 신호면 다가가기 실천 제외.
- **디자인**: "달밤에서 새벽으로" — 밤 화면(#012F53 + 금빛 선화) → 카드 뒤집기 새벽 광채 → 아침 크림(#FEF3DE) 결과. 고운바탕 + Noto Sans KR. 카드 2:3 WebP(시안, 교체 예정).
- **포지셔닝**: 예언·운세가 아니라 전문 상담사가 만든 자기이해 웰니스 콘텐츠.
