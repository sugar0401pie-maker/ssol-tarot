(2026-10-07 owner가 채팅으로 전달한 원문. 개발 기준은 docs/spec/tarot-master-spec.md이며, 충돌하면 마스터 스펙이 우선.)

쏠 웰니스 하우스의 세 번째 웰니스 테스트. 기준일 2026-10-07. 최신 개발 자료는 `웰니스타로_개발패키지_v2.2.zip`(마스터 스펙·카드 데이터 JSON·화면 흐름/셔플/안전/조립/검증 코드·AI 프롬프트·예시 리포트·처방 검수표·디자인 가이드·미리보기).

1. 한 줄 요약
닉네임을 정하고, 원하면 고민을 적은 뒤(건너뛰기 가능) 카드를 섞고(다시 섞기 가능) 22장 중 마음 가는 3장을 직접 뽑아 지금의 마음 / 나를 붙잡는 것 / 다음 한 걸음을 보고 웰니스 실천을 제안받는다. 카드는 예언이 아니라 고민을 비추는 거울.

2. 시작 흐름 (v1.2)
1. 인트로: 디저트 테스트와 동일(히어로 + 참여자 수 + "테스트 하기"), 히어로 자리에 바다 친구들이 한 명씩 무작위로 지나가는 연출
2. 환영: "쏠 타로 하우스에 오신 당신을 환영합니다."(큰 글씨) / "당신을 뭐라고 불러드리면 될까요?"(작은 글씨) + 닉네임 입력 + [이렇게 불러주세요]
3. 경험 질문: "{닉네임}님, 오늘은 어떤 고민을 가져오셨나요?" / "타로카드는 처음이신지요?" — [전에 본 적이 있어요] [네, 처음이에요]
4. 처음이면 안내: "오늘 {닉네임}님의 고민을 타로카드가 어떻게 비춰 주는지 들어봅시다. 우리 쏠 하우스만의 특제 레시피로 …웰니스 제안을 해드릴게요. 이제 한 번 해볼까요?" → [네, 좋아요!]
5. 고민 쓰기: "좋습니다. 먼저 {닉네임}님의 고민을 편하게 작성해주세요. 구체적으로 쓸수록 도움이 됩니다. 고민을 굳이 작성하지 않으셔도 타로카드는 볼 수 있어요." — [제출하기] / [고민은 마음속으로만 생각하고 싶어요](바로 카드 화면으로)
- 확인 화면 없음. AI 분류는 셔플 연출 동안 백그라운드. 위기 신호면 안전 안내로 전환.
- 고민 미작성 모드: 분류·연결 한 줄·이야기 AI 없이 고정 문장으로 결과 조립(AI 호출 0회).

2-1. 고민 분류 (v1.3)
- 영역은 디저트 테스트의 생활 영역 6개: 직업·커리어 / 진로·자기계발 / 연애 / 가족 / 교우·사회관계 / 재정·생활안정. 섞이면 감정이 가장 크게 걸린 쪽. 무대 없는 '나 자신'(자존감·감정 기복·삶의 의미)은 삶의 방향과 함께 진로·자기계발로 묶고 self_focus 표시, 결과 문장은 "나 자신과 삶의 방향에 대한 고민"(v1.5 결정).
- 감정 8개, 필요 6개는 그대로. 고민 예시 문장 60개(영역별 8 + 경계 6 + 안전 6)를 분류 기준·프롬프트 예시·정확도 점검에 사용(상담사 검수 전).
- 안전: 서버 키워드(즉시) + AI 판단(셔플 동안) 중 높은 쪽. '자살'·'자해'는 원문 그대로 검사(띄어쓰기 제거 오탐 방지).

3. 카드 뽑기 (v1.1)
- 셔플: "이제 카드를 선택할 시간입니다. 가장 고민되는 부분을 생각하면서 골라주세요. 최대한 구체적으로 생각하고 뽑을수록 좋아요." + 섞는 연출(최소 3초) → "카드가 잘 섞였습니다. 원하신다면 다시 섞으셔도 돼요." [지금 뽑을게요] / [다시 섞을게요]
- 뽑기: 22장 한 화면(모바일 2줄 부채꼴), "고민을 되새기면서 가장 마음이 가는 카드 3개를 뽑아주세요." 누르는 즉시 앞면으로 뒤집혀 슬롯으로. 뽑은 순서 = 위치.
- "카드를 다 뽑았어요. 이제 설명을 보러 가볼까요?" [네, 좋습니다.] — 3장째에 서버가 백그라운드로 결과 준비.
- 모든 대기 화면: "{닉네임}님의 타로 결과를 분석하고 있어요... (n초 경과)". 오래 걸릴 때 안내는 미정.
- 셔플은 서버에서만(crypto). 해석 3층: ① 카드 고정 해석 ② 고민 읽기 ③ AI가 ①을 고민에 엮음.

3-1. 디자인 (v1.4, 카드 시안 기준)
- 기준 문서: docs/design/design-guide.md. 분위기 "달밤에서 새벽으로": 인트로~뽑기·대기는 카드 뒷면의 밤(남색 #012F53 + 금빛 선화 #E3C68E + 달빛 #FCEFD4), 카드 뒤집는 순간 새벽 광채, 결과·리포트는 앞면의 크림 아침(#FEF3DE, 제목 #204870). 고운바탕(제목·카드명) + Noto Sans KR(본문).
- 카드 뒷면은 달 물결 시안으로 확정. 9번은 관계성 테스트 '바다의 노인' 그림으로 다시 그림. 앞면 그림은 시안이며 교체 예정. 파일명 유지 시 코드 수정 없이 교체, 카드명은 하단 크림 띠(높이 약 92%)에 웹 글자.
- 결과 카드 확대(v2.2): 결과 맨 위 카드 3장 사진을 누르면 카드가 제자리에서 들려 가운데로 확대(약 0.46초, 살짝 기울었다 자리 잡기), 다시 누르면 같은 길로 제자리에. 움직임 줄이기 설정이면 페이드만.

5. 결과와 리포트 — 카드별 섹션, 두 번째 카드까지 무료 (v2.2)
- 맨 위: 뽑은 카드 3장 사진(역방향은 180도 회전), 누르면 확대.
- 무료: 1 오늘 당신에게 온 세 장 / 2 첫 번째 카드 · 지금의 마음 / 3 두 번째 카드 · 나를 붙잡는 것. 위험 신호(watch·violence) 안내 박스도 무료.
- 여기부터 블러, 1,900원(리포트만, 채팅권 없음): 4 세 번째 카드 · 다음 한 걸음 / 5 세 장이 함께 들려주는 이야기 / 6 웰니스 처방 / 7 이번 주 실천 카드 / 8 쏘웰라 안내(유료 구간).
- 공유 카드는 카드 3장·이름·위치·방향만.

6. 지켜야 할 원칙
- 예언·운명·맞힌다 표현 금지. 진단 금지, 상대 판정·관계 지속/종료 권유 금지.
- 안전: 서버 키워드 + AI 판단 중 높은 쪽. urgent면 카드 진행 중단 + 안전 안내. 폭력·통제 신호면 다가가기 실천·처방 제외(D19).
- 공유 카드에 고민 원문·감정·해석을 넣지 않는다. 결제 전 유료 본문은 클라이언트로 보내지 않는다. 유료 리포트는 미리 만들지 않는다.
