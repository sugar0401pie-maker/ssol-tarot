# 쏠 타로 하우스 — 디자인 가이드 (시안 v0)

> 기준일 2026-10-07. 카드 앞면 22장과 뒷면은 **시안**이며 나중에 바뀝니다. 그래서 이 가이드는 그림이 바뀌어도 그대로 쓰는 **분위기·색·글꼴·장식 원칙**과 **교체 규칙** 중심으로 썼습니다. 그림은 파일명만 같으면 갈아 끼울 수 있습니다.
> 화면 미리보기: `design-preview.html`(브라우저로 열기). 시안 이미지: `images/`(720×1080 WebP, 원본 1024×1536 PNG는 별도 보관).

---

## 1. 분위기 한 줄 — "달밤에서 새벽으로"

카드 두 면이 서로 다른 시간을 담고 있고, 사용자 여정도 그 순서를 따라갑니다.

| | 카드 뒷면 = **달밤** | 카드 앞면 = **새벽** |
|---|---|---|
| 느낌 | 신비, 고요, 집중 | 위로, 온기, 희망 |
| 색 | 깊은 남색 바탕 + 금빛 선화 + 크림빛 보름달 | 수채화 새벽 바다(옅은 하늘·복숭아빛) + 크림 프레임 |
| 장식 | 이중 금선 테두리, 모서리 조개·불가사리, 점선 원호, 네 갈래 반짝임, 초승달, 달 속 두 물결 | 남색 외곽선 + 금빛 안쪽 선, 모서리 물결 소용돌이, 하단 빈 크림 띠 |
| 쓰는 화면 | 인트로 ~ 고민 쓰기, 셔플, 뽑기, 대기 | 카드를 뒤집은 순간부터 결과·리포트 |

**여정의 흐름**: 밤바다에서 고민을 꺼내고 카드를 섞어 뽑는다(남색) → 카드를 뒤집는 순간 새벽빛이 번진다(남색 배경 위에 앞면 카드 + 은은한 금빛 광채) → 해석은 크림색 아침 화면에서 편안하게 읽는다.

## 2. 색 토큰

시안에서 직접 뽑은 색을 기준으로, 기존 쏠 로고 색감(관계성 테스트 7장)과 함께 씁니다. 시안이 바뀌면 `night`, `gold`, `moon`, `card-cream`, `card-line`만 다시 뽑아 교체하면 됩니다.

| 토큰 | 값 | 출처 | 쓰는 곳 |
|---|---|---|---|
| `--night` | `#012F53` | 카드 뒷면 바탕 | 밤 화면 배경(인트로~뽑기, 대기), 결제 카드, 하단 고정 바 |
| `--night-deep` | `#001E38` | `--night`에서 파생 | 밤 화면 아래쪽 그라데이션, 모달 딤 |
| `--gold` | `#E3C68E` | 뒷면 금빛 선화 | 장식선, 테두리, 반짝임, 밤 화면의 아웃라인 버튼, 선택 배지 |
| `--gold-soft` | `#F3E2BE` | 뒷면 밝은 금선 | 밤 화면 큰 제목, 강조 글자 |
| `--moon` | `#FCEFD4` | 보름달 | 밤 화면 본문 글자, 채움 버튼 배경(글자는 `--night`) |
| `--card-cream` | `#FEF3DE` | 앞면 프레임·띠 | 아침 화면(결과·리포트) 페이지 배경 |
| `--card-line` | `#204870` | 앞면 남색 외곽선 | 결과 카드 테두리, 아침 화면 제목 |
| `--dawn-sky` | `#A8C4DE` | 앞면 하늘 | 보조 배경, 비활성 칩, 섹션 구분 띠 |
| `--dawn-peach` | `#FAE4CD` | 앞면 수평선 빛 | 강조 배경(무료 해석 박스), 카드 뒤집기 광채 |
| `--navy` | `#013566` | 쏠 로고 | 아침 화면의 버튼(채움), 링크 |
| `--ink` | `#1C2B3A` | 로고 파생 | 아침 화면 본문 |
| `--white` | `#FFFFFF` | 로고 | 리포트 카드 배경 |

**대비 규칙**
- 밤 화면: 본문은 `--moon`, 큰 제목은 `--gold-soft`, 작은 보조 글은 `--moon` 80% 불투명. 금색(`--gold`)은 장식·테두리용이고 14px 이하 본문 글자에는 쓰지 않습니다.
- 아침 화면: 본문은 `--ink`, 제목은 `--card-line`. 금색은 구분선·반짝임 장식에만 씁니다(크림 위 금색 글자는 대비가 낮음).
- 결제 카드·하단 고정 바처럼 아침 화면 안의 강조 영역은 밤색(`--night` 배경 + `--moon` 글자)으로 뒤집어 눈에 띄게 합니다.

```css
:root{
  --night:#012F53; --night-deep:#001E38; --gold:#E3C68E; --gold-soft:#F3E2BE; --moon:#FCEFD4;
  --card-cream:#FEF3DE; --card-line:#204870; --dawn-sky:#A8C4DE; --dawn-peach:#FAE4CD;
  --navy:#013566; --ink:#1C2B3A; --white:#FFFFFF;
}
```

## 3. 글꼴

| 용도 | 글꼴 | 이유 |
|---|---|---|
| 큰 인사·질문(환영, "타로카드는 처음이신지요?"), 카드명, 섹션 제목 | **고운바탕(Gowun Batang)** 700 | 금빛 선화·달밤 분위기에 맞는 정갈한 명조. 디저트의 귀여운 Jua 대신 차분한 느낌 |
| 본문, 버튼, 입력란, 안내 | **Noto Sans KR** 400/500 | 디저트·관계성 테스트와 같은 본문 글꼴(가독성) |

- 고운바탕은 제목·카드명에만 씁니다. 긴 본문까지 명조로 쓰면 모바일에서 읽기 어렵습니다(디저트 테스트에서 귀여운 글꼴을 본문에 썼다가 되돌린 것과 같은 원칙).
- 크기 기준(모바일): 큰 인사 26px / 질문 18px / 카드명 18px / 본문 15px / 보조 13px.

## 4. 장식 요소 (뒷면에서 가져와 화면에 쓰는 것)

| 요소 | 화면에서 쓰는 곳 | 만드는 법 |
|---|---|---|
| 이중 금선 테두리 + 모서리 조개·불가사리 | 밤 화면 전체를 감싸는 프레임(인트로~고민 쓰기) | SVG 4개 모서리 조각 + 선. 화면 크기에 맞춰 늘어나게 |
| 네 갈래 반짝임 ✦ + 점선 | 섹션 구분선(밤·아침 공통), 질문 위 장식 | SVG 아이콘 1개 + `border-top: dotted` |
| 달 속 두 물결 엠블럼 | 대기 화면(천천히 회전·숨쉬기), 셔플 중앙, 공유 카드 워터마크 | 뒷면 중앙 원을 잘라 쓴 이미지 또는 SVG 단순화 버전 |
| 초승달 원호 | 버튼 위 작은 장식, 슬롯 라벨 위 | SVG |
| 은은한 금빛 광채 | 카드를 뒤집는 순간 카드 뒤 | `radial-gradient(var(--dawn-peach) → transparent)` 0.6초 페이드 |
| 반짝이는 별가루 | 셔플·밤 화면 배경 | 작은 점 10~20개, 3~6초 주기로 깜빡임(움직임 줄이기 설정 시 정지) |

**버튼**
- 밤 화면 기본: `--moon` 채움 + `--night` 글자, pill 모양. 보조: 투명 + `--gold` 1px 테두리 + `--moon` 글자.
- 아침 화면: 기존 쏠 규칙(`--navy` 채움 pill + 흰 글자, 보조는 아웃라인).
- 두 버튼이 나란히 나올 때(지금 뽑을게요 / 다시 섞을게요, 전에 본 적이 있어요 / 네, 처음이에요)는 같은 너비로 세로 배치, 주 행동이 위.

**입력란(닉네임·고민)**: 밤 화면 위 `--moon` 배경 + `--ink` 글자 + `--gold` 1px 테두리, 모서리 14px. 포커스 시 금빛 그림자.

## 5. 화면별 적용

| 화면 | 배경 | 핵심 연출 |
|---|---|---|
| 인트로 | 밤 + 별가루 + 수평선 | **바다 친구들이 한 명씩 무작위로 지나가는 연출**(5-1) + 제목 + 참여자 수 + [테스트 하기] (디저트와 같은 구성) |
| 환영 | 밤 + 금선 프레임 | 반짝임 → 큰 글씨(고운바탕) 환영 인사 → 작은 글씨 질문 → 입력란 → [이렇게 불러주세요] |
| 경험 질문 / 처음 안내 | 밤 + 금선 프레임 | 같은 레이아웃. 처음 안내는 본문 문단을 `--moon`으로, 위아래에 초승달 장식 |
| 고민 쓰기 | 밤 + 금선 프레임 | 큰 입력란, 아래 작은 글씨 고지(`--moon` 70%) |
| 셔플 | 밤 + 별가루 | 중앙에 뒷면 카드 더미, 섞일 때 금빛 잔상. 안내문은 위쪽 고운바탕 |
| 뽑기 | 밤 | 위 슬롯 3개(점선 금테 + 초승달 + 위치명), 아래 22장 뒷면 부채꼴 |
| 다 뽑음 | 밤 → 새벽 광채 | 앞면 3장이 금빛 광채와 함께 나란히, 카드명은 각 카드 하단 크림 띠에 웹 글자로 |
| 대기 | 밤 | 달 속 물결 엠블럼 천천히 회전 + "{닉네임}님의 타로 결과를 분석하고 있어요... (n초 경과)" |
| 결과·리포트 | 아침(`--card-cream`) | **(v2.7) 옆으로 넘기는 8쪽** — 5-3 참고. 1~4쪽 무료, 5쪽은 메인 문구 + 첫 줄 + 마무리 문장 뒤 블러 + 밤색 결제 카드, 6~8쪽 잠김 |
| 공유 카드 | 밤 + 금선 프레임 | 앞면 3장 + "{닉네임}님의 웰니스 타로 세 장" + 달 물결 워터마크 |
| 안전 안내 | 아침(`--card-cream`) | 장식 최소화, 연락처 카드가 먼저 보이게. 신비 연출(별가루·반짝임) 없음 |

## 5-1. 인트로 연출 — 바다 친구들 지나가기

첫 화면 가운데의 밤바다 수평선 위로, 카드 속 귀여운 바다 친구들이 **한 명씩 무작위로** 헤엄쳐 지나갑니다. `design-preview.html`의 1번 화면에서 실제로 움직이는 모습을 볼 수 있습니다.

| 항목 | 값 |
|---|---|
| 등장 순서 | 21종(캐릭터 20 + 바다의 노인)을 섞은 주머니에서 하나씩 꺼냄 → 한 바퀴를 다 돌기 전엔 같은 친구가 다시 나오지 않고, 바퀴가 바뀔 때도 바로 앞 친구와 겹치지 않음. 화면 연출이라 `Math.random`으로 충분 |
| 방향 | 매번 왼쪽→오른쪽 또는 오른쪽→왼쪽 무작위 |
| 움직임 | 한 친구가 약 4.2초에 걸쳐 가로질러 감(들어와서 가운데서 잠깐 느려졌다가 나감) + 위아래로 둥실둥실(1.6초 주기, ±10px, 살짝 기울기) |
| 간격 | 3초마다 다음 친구 출발 → 앞 친구가 나갈 즈음 다음 친구가 들어와 화면이 비지 않음 |
| 모양 | 시안: 카드 그림에서 캐릭터 부분을 원형으로 잘라 금빛 테두리 + 은은한 금빛 광채, 아래에 이름(고운바탕 13px, `--gold-soft`) |
| 최종 에셋 | **관계성 테스트의 캐릭터 일러스트(투명 PNG)**를 그대로 쓰는 것을 권장 — 원형 틀 없이 캐릭터만 물 위를 헤엄치면 더 귀엽고 가볍습니다. 파일명 예: `friend-{캐릭터 영문}.webp`, 높이 240px |
| 움직임 줄이기 | `prefers-reduced-motion`이면 가운데에서 페이드 인·아웃만 |
| 성능 | 화면에 한 번에 1~2명만, `transform`·`opacity`만 애니메이션, 이미지는 첫 화면 진입 때 미리 불러오기(21장 × 약 10KB) |
| 접근성 | 대체 텍스트 "{캐릭터} — {카드명}", 장식 연출이라 버튼 포커스 순서에는 넣지 않음 |

## 5-2. 결과 카드 확대 연출 (v2.2)

결과 페이지 맨 위의 카드 3장 사진을 누르면, 카드가 **제자리에서 들려 화면 가운데로 날아오며** 커집니다. 다시 누르면 같은 길로 **제자리에 내려앉습니다.** `design-preview.html` 9번 화면에서 실제로 눌러 볼 수 있습니다.

| 항목 | 값 |
|---|---|
| 배치 | 결과 첫 화면 맨 위, 뽑은 순서(지금의 마음 → 나를 붙잡는 것 → 다음 한 걸음)대로 가로 3장. 역방향은 그림을 180도 돌려 보여 주고 아래에 "카드명 · 역방향". 그 아래 작은 안내 "카드를 누르면 크게 볼 수 있어요" |
| 세 번째 카드 | 결제 전에도 사진·카드명은 선명(이미 뒤집어 본 카드). 확대도 가능 |
| 열기 (0.46초) | 공유 요소 전환(FLIP): 썸네일 자리를 비우고 같은 카드가 그 위치에서 출발 → 절반쯤에서 살짝 위로 들리며 `rotateY(-16°) rotate(-4°)` → 가운데에서 `scale 1.04 · rotateY(5°)`로 한 번 넘쳤다가 0°로 자리 잡기. 곡선 `cubic-bezier(.22,.8,.24,1)` |
| 확대 크기 | 화면 너비의 약 68%, 세로 가운데보다 살짝 위. 그림자 `0 18px 40px rgba(0,0,0,.6)` |
| 배경 | 밤색(`--night-deep`) 72% 덮개가 0.45초에 걸쳐 깔림. 아래에 "카드명 · (역방향) · 다시 누르면 돌아가요" 캡션(고운바탕 13px, 밤색 알약 배경) |
| 닫기 (0.4초) | 카드·덮개·Esc 키 중 아무거나 → 살짝 반대로 기울었다가(`rotateY(8°) rotate(2°)`) 원래 썸네일 자리로 줄어들며 돌아감 → 썸네일 다시 보임. 곡선 `cubic-bezier(.5,0,.3,1)` |
| 연타 방지 | 움직이는 동안에는 다른 카드를 열거나 닫지 않음 |
| 움직임 줄이기 | `prefers-reduced-motion`이면 날아가기·기울기 없이 가운데에서 페이드 인/아웃(0.2초) |
| 성능 | `transform`·`opacity`만 애니메이션. 확대용 이미지는 결과 진입 때 미리 불러온 원본(가로 720px webp) 사용 |
| 접근성 | 썸네일은 버튼 역할(`role=button`, Enter·Space로 열기), 대체 텍스트 "카드명 — 캐릭터", 닫으면 원래 썸네일로 포커스 복귀 |

## 5-3. 결과 넘겨 보기 (v2.7)

웹툰처럼 한 쪽씩 옆으로 넘기는 결과 화면입니다. `06_디자인/result-swipe-preview.html`에서 실제로 넘겨 볼 수 있어요(결제 전/후 전환 버튼 포함).

| 항목 | 값 |
|---|---|
| 넘기기 | 가로 스크롤 스냅(`scroll-snap-type: x mandatory`) — 손가락 스와이프, 좌우 버튼(44px 원형), 키보드 ← → |

## 7. 시안 교체 규칙

1. 비율 2:3, 원본 1024×1536 이상을 유지합니다.
2. 앞면은 **글자·번호 없이**, 하단 크림 띠를 비워 둡니다. 띠 위치가 바뀌면 6장의 87%~97% 값을 다시 재서 고칩니다.
3. 파일명은 그대로(`card-00-splash.webp` …) 두면 코드 수정 없이 교체됩니다.
4. 색이 크게 바뀌면 2장의 시안 출처 토큰 5개만 다시 뽑습니다(나머지는 로고 기준이라 유지).
5. 캐릭터는 기존 쏠 캐릭터 원래 모습·색을 유지합니다. 바다의 노인은 헤밍웨이 이름·얼굴·원문 인용 없이.
6. 21번 단체 카드는 캐릭터가 많아 AI로 한 번에 그리기 어렵습니다. 최종본은 캐릭터를 직접 배치하는 방식을 권장합니다.

## 5-4. 결과 10쪽 · 요약 한 줄 · 다음으로 버튼 (v2.13)

- **[다음으로 →]**: 쪽 본문 맨 끝에 테두리형 버튼(남색 선 1.5px, 둥근 24px). 누르면 다음 쪽으로 넘김. 4쪽은 채운 버튼 '세 장 함께 읽기', 10쪽은 없음. 아래 좌우 화살표와 함께 둠.

## 5-5. 버튼·표딱지·결제 전 블러 (v2.14, CSO 결정)

- **쪽 끝 버튼 줄**: 왼쪽 작은 **[돌아가기]**(너비 약 1/3, 테두리 남색 1.5px · 글자 남색 · 채움 없음) + 오른쪽 **[다음으로 →]**(남색 `--night` 채움 · 글자 달빛 베이지 `--moon`). 1쪽은 [다음으로]만, 4쪽은 다음 버튼 글자가 '세 장 함께 읽기 →', 10쪽은 [돌아가기]만. 5-4의 테두리형 [다음으로]는 이걸로 바뀜.

## 5-6. 무료 범위 줄이기 · 굵게 쓰기 (v2.15, CSO 결정)

- **2~4쪽(무료)**: 카드 사진·이름 → 핵심 메시지 → 어떤 카드인가요(키워드 + 기본 설명 + 이럴 때 나오는 카드) → (1번째 카드만) 감정 문장 → 위치 해석 → 고민 연결 한 줄(AI). **상황 질문 2개와 '조금 더 들여다보기'는 빠짐.**
- **5쪽 블러 아래(결제 후)**: 흐름 한 줄 → 굵은 요약 → 세 장의 이야기 → 패턴·구간 → **'카드별로 조금 더 들여다보기'**(점선 위 구분선 + 큰 소제목) — 카드마다 ●위치 · 카드명 → 질문 소제목 + 질문 2개 → '조금 더 들여다보기' 문단 2개.
- **굵게**: 문단의 첫 문장(요약)을 굵게 — 기본 설명, 위치 해석, 조금 더 들여다보기 문단, 6쪽 국면·걸림돌 문단. 한 문장짜리 문단은 굵게 하지 않음. 굵은 글자는 남색(`--line`). 쪽 맨 위 요약 한 줄(5-4)과 함께 쓰여도 한 화면에 굵은 문장이 3~4개를 넘지 않게 하는 게 원칙.


## 5-7. 곱씹어 볼 질문 · 6↔7쪽 순서 · 들여다보기 두 안 (v2.16)

- **5쪽 블러 아래 끝**: 카드별 나열 없이 소제목 **"이 질문들을 곱씹어 볼까요?"** + 질문 3개(말머리 기호, 굵게). 자리마다 모양: 지금의 마음 "지금, ~않나요?" / 나를 붙잡는 것 "혹시 '~' 생각이 나를 붙잡고 있지는 않나요?" / 다음 한 걸음 "앞으로 ~ 어느 쪽이 더 무겁게(가볍게) 느껴지나요?"
- **순서**: 6쪽 내 고민에 대어 보면 → 7쪽 해결의 흐름.
- **조금 더 들여다보기 — 두 안**(`copy.result.deep_mode`, 기본 inline)
  - **A안 녹여 쓰기(inline)**: 6쪽 문단 뒤에 세 카드의 들여다보기 첫 단락을 **"지금의 마음에서 보면, / 나를 붙잡는 것에서 보면, / 다음 한 걸음에서 보면,"**(굵게)으로 이어 씀. 7쪽은 국면 문단 뒤에 다음 한 걸음 카드의 작은 제안, 걸림돌 문단 뒤에 붙잡는 것 카드의 작은 제안(첫 문장 굵게).
  - **B안 접어 두기(fold)**: 6쪽 끝에 접힌 상자 "세 장을 하나씩 더 들여다보기 ▾"(누르면 카드별 첫 단락 세 개), 7쪽 끝에 "풀어 가는 데 도움이 될 작은 제안 ▾"(다음 한 걸음·붙잡는 것 카드의 제안). 상자: 연한 크림 바탕, 둥근 14px, 남색 굵은 제목 + 금색 ▾.
- **굵게 추가**: 결 패턴·여정 구간 문장의 뜻(두 번째 문장), 웰니스 처방·실천 카드의 말머리 기호(•) 줄 전체.


## 5-8. 2~4쪽 카드 화면 · 자리별 머리말 (v2.17, CSO 결정)

- **카드 그림을 화면 너비 가득**(둥근 14px). 카드 아래 이름 캡션 없음 — 실제 카드 그림에 이름이 들어 있음. 1쪽 작은 카드도 캡션 없이 역방향만 작게 표시.
- 카드 바로 아래 **한 상자**(왼쪽 금색 선 3px, 바탕은 쪽 바탕과 같은 크림 — 흰 바탕 없음): 자리(금빛 작은 글자) → **카드 이름**(굵게) + 캐릭터·방향(작은 회색) → 핵심 메시지. 카드 이름과 핵심 메시지는 같은 글꼴·크기(Gowun Batang 17px).
- **'어떤 카드인가요' 대신 자리별 머리말**(Gowun Batang 19px, 위 점선): 지금의 마음 "카드가 말하는 지금의 마음은" / 붙잡는 것 "지금 나를 붙잡고 있는 것은" / 다음 한 걸음 "카드가 비추는 다음 한 걸음은" → 바로 아래 굵게 "‘(메인 문구 조각)’이에요." (`copy.result.card_headings`, 문구는 바꿀 수 있음)
- **5쪽 '이 질문들을 곱씹어 볼까요?' 질문은 굵게 하지 않음**(말머리 ◦ — 처방·실천의 • 줄만 굵게).
