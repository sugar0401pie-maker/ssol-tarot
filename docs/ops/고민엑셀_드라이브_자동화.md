# 고민 누적 엑셀 → 구글 드라이브 자동 저장 (보관용 안내)

상태: **코드는 들어가 있고, 설정을 안 해서 꺼져 있음** (2026-11-19, owner "지금은 매일 직접 내려받으니 안 함 — 테스트를 여러 개 동시에 굴리게 되면 필요").
설정 값 두 개가 없으면 이 기능은 아무것도 하지 않는다(메일에도 아무 말 없음).

## 하는 일
- 월·목 아침 9시쯤(한국 시간), 처음부터 전날까지의 타로 고민을 엑셀 한 파일로 만들어 owner 구글 드라이브 폴더에 **새 파일**로 올린다.
  - 파일 이름: `ssol-tarot_worries_until_{날짜}.xlsx`
  - 칸: 관리자 화면 '처음부터 그 날까지' 엑셀과 같고 **닉네임·이메일·로그인 수단만 뺌**(분석용).
- 같은 날 아침 관리자 메일(숫자만)에 "드라이브에 올렸어요(○건) + 파일 링크" 한 줄이 붙는다. 고민 글은 메일로 가지 않는다.
- 요일을 바꾸려면 `lib/admin/dailyReport.ts`의 `WORRY_EXPORT_WEEKDAYS`(0=일 … 6=토).

## 왜 Apps Script를 거치나
서버(구글 서비스 계정)는 개인 구글 드라이브에 파일을 만들 저장 공간이 없다. 그래서 owner 계정으로 도는 작은 프로그램(Apps Script 웹 앱)이 파일을 받아 owner 드라이브에 저장한다. 비밀값이 맞지 않으면 아무것도 저장하지 않는다.

## 켜는 방법 (한 번만, 10분 정도)
1. 구글 드라이브에 엑셀을 모을 폴더를 만들고, 폴더 주소 맨 끝(`folders/` 뒤) 글자 = **폴더 ID**를 복사.
2. script.google.com → 새 프로젝트 → 기존 코드를 지우고 `docs/ops/drive-upload-apps-script.gs` 내용을 그대로 붙여넣기.
3. 프로젝트 설정(톱니바퀴) → 스크립트 속성 두 개:
   - `SECRET` = 긴 무작위 글자(40자 정도)
   - `FOLDER_ID` = 1번의 폴더 ID
4. 배포 → 새 배포 → 유형 **웹 앱**, 실행 사용자 **나**, 액세스 **모든 사용자** → 권한 허용 → **웹 앱 URL** 복사.
5. Vercel(한국어 타로 프로젝트) → Environment Variables:
   - `DRIVE_UPLOAD_URL` = 4번 웹 앱 URL
   - `DRIVE_UPLOAD_SECRET` = 3번 `SECRET`과 똑같은 값
   - `CRON_SECRET` = 긴 무작위 글자(매일 관리자 메일·이 기능을 부르는 데 필요 — 이미 있으면 그대로)
   → 다시 배포.

## 시험해 보기
Vercel 배포 뒤, 요일과 상관없이 한 번 올려 보려면 cron 주소를 `?worries=1`로 부른다(`Authorization: Bearer <CRON_SECRET>` 필요):
`GET https://tarot.ssolwellnesshouse.com/api/cron/admin-report?worries=1` — 이때 관리자 메일도 한 통 간다.

## 끄기
Vercel에서 `DRIVE_UPLOAD_URL`이나 `DRIVE_UPLOAD_SECRET`을 지우고 다시 배포. (매일 메일까지 끄려면 `CRON_SECRET`을 지우거나 `vercel.json`의 crons 줄 삭제.)

## 여러 테스트로 넓힐 때
지금은 타로(`tarot_sessions`)만 만든다. 다른 테스트(아스트로·디저트 등)는 각 저장소에 같은 방식(`lib/server/driveUpload.ts` + 같은 Apps Script 주소, 파일 이름에 테스트 이름)을 넣으면 한 폴더에 모을 수 있다. Apps Script는 하나로 같이 써도 된다.

## 관련 코드
- `app/api/cron/admin-report/route.ts` — cron 진입점(`vercel.json`, 매일 00:00 UTC)
- `lib/server/admin.ts` `sendAdminDailyReport` — 메일·엑셀
- `lib/server/driveUpload.ts` — 드라이브 올리기
- `docs/ops/drive-upload-apps-script.gs` — owner 계정에 붙여넣을 스크립트

## 개인정보
고민 원문이 owner 드라이브에 쌓인다. 폴더 공유 범위는 owner만으로 두고, 지난 파일은 주기적으로 지운다(방침의 보관 기간과 맞추기 — 로그인 없이 본 결과는 보관 기간이 지나면 DB에서는 지워지지만 드라이브 사본은 남는다).
